# AGENTS.md

Тестовое задание T-LAB, направление **Mechanistic Interpretability**.
Постановка целиком — в [NOTES.md](NOTES.md). Прочитай её перед любой работой.

## Раскладка

| путь | что там | в git |
|---|---|---|
| `NOTES.md` | задание, сетап, лог, идеи, результаты | да |
| `baseline.py` | наивный стиринг `h + alpha*v`, парето-кривая | да |
| `report.md` | финальный отчёт (создаётся в конце) | да |
| `datasets/` | корпуса для обучения денойзера, кэш активаций | нет |
| `runs/` | чекпойнты, json с метриками, графики | нет |
| `tmp/` | всё, что нагенерил агент: черновики, дампы, одноразовые скрипты | нет |
| `ext/sparse_autoencoder` | клон OpenAI SAE, только читать | нет |

## Правила

- Новый код кладём в корень отдельным файлом (`train_denoiser.py`, `eval_steering.py`),
  не в подпакеты. Плоско и минимально.
- `baseline.py` не трогаем: это точка отсчёта, её числа должны воспроизводиться.
- Всё, что генерится «на подумать», — в `tmp/`. Он в `.gitignore` и его не жалко.
- Артефакты запусков только в `runs/<tag>/`. Никаких чекпойнтов в корне.
- Никаких новых зависимостей без записи в `requirements.txt`.
- Валидационные векторы $v$ фиксируются в NOTES → «Сетап» **до** обучения денойзера.
  Денойзер не должен их видеть — это главное методологическое условие задания.
- Каждый запуск — строка в NOTES → «Лог»: дата, команда, что вышло.
